# Contributing to ChessGameReview

Thank you for your interest in contributing to **ChessGameReview**!

## Development Setup

```bash
git clone https://github.com/<your-username>/chess-game-review.git
cd chess-game-review
npm install
npm run dev
```

## Build Verification

```bash
npm run build
```

## Code of Conduct

Please adhere to our [Code of Conduct](CODE_OF_CONDUCT.md) in all interactions.
